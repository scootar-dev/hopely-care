B. KONTEKS PRODUK
==================================================

Hopely Care adalah AI-powered psycho-oncology companion untuk pasien kanker.

Hopely Care BUKAN:
- alat diagnosis kanker;
- pengganti dokter;
- pengganti psikolog;
- pengganti tenaga kesehatan;
- sistem penentu terapi;
- sistem pemberi resep;
- aplikasi yang memberikan diagnosis gangguan psikologis.

Tujuan Hopely Care adalah memahami perjalanan wellbeing emosional dan fisik pasien kanker secara longitudinal.

Sistem menggabungkan:

Daily Wellbeing Check-In

Konsep kunci Hopely Care adalah:

Pahami bagaimana kondisi pasien berubah sepanjang perjalanan pengobatannya."

==================================================
O. LONGITUDINAL TREND ENGINE
==================================================

Ini adalah diferensiasi utama Hopely Care.

Endpoint:

POST /v1/ai/trend/analyze

Analisis minimal 7–14 hari bila data tersedia.

Gabungkan:

daily check-in
symptoms
emotion signals
treatment timing

Jangan hanya:

if mood < 2 -> bad

Gunakan combination dari:

rolling averages;
rate of change;
baseline comparison;
moving trend;
anomaly detection jika relevan;
emotion signals.

Contoh output:

{
   "period_days": 14,

   "trends": {
      "mood": "declining",
      "anxiety": "increasing",
      "sleep": "declining",
      "energy": "declining"
   },

   "significant_changes": [],

   "contextual_patterns": [
      {
        "event": "chemotherapy",
        "observation": "fatigue increased following treatment"
      }
   ],

   "overall_direction": "needs_attention"
}

Jangan menyimpulkan sebab-akibat medis.

Gunakan wording:

"terlihat berdekatan dengan"
"terjadi setelah pencatatan treatment"

"treatment menyebabkan..."
